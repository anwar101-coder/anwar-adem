# Anwar Adem — Personal Portfolio

A modern, responsive personal portfolio website showcasing my work, technical skills, education, and experience as a Computer Science student and freelance web developer.

🌐 Live Demo

View Portfolio

✨ Features
Responsive design for desktop, tablet, and mobile
Modern and interactive user interface
Featured projects with project details
Skills and technology showcase
Education and professional background
Freelance web development services
Contact and social media links
Smooth animations and interactive elements
🛠️ Tech Stack
Built with React, TypeScript, TanStack Start, TanStack Router, Tailwind CSS, and Vite, with Motion and Lucide React used for interactive UI and animations.
📌 About the Project

This portfolio was created to provide a central place to showcase my development work and professional journey. It combines a clean visual design with interactive elements to present my projects, technical interests, and experience.

The project is continuously updated as I learn new technologies and build new projects.

🚀 Run Locally
git clone https://github.com/anwar101-coder/anwar-adem.git
cd anwar-adem
npm install
npm run dev

The development server will start locally and provide a URL where the portfolio can be viewed in the browser.
