Contact & Footer	Quick inquiry form, calendar booking embed, direct email copy button, and social links.	Frictionless path to make contact.
Page 2: Project Case Study Template (Individual Modal / Sub-page)
•	Case Study Header: Live site link, client name, technical stack badges, and project release date.
•	Problem & Architecture Solution: Breakdown of project requirements, database choices, and frontend framework selections.
•	Key Features & Interactive Demo: Embedded UI previews, feature breakdowns, and backend configuration highlights.
•	Results & Metrics: Measurable outcomes (e.g., page load acceleration, conversion rate lift, user flow simplification).
3. Design Style & Visual Direction
•	Design Aesthetic: Modern Minimalist Bento Grid — structured, clean, card-based layout with high contrast and generous negative space.
•	Color Palette:
o	Background: Dark Slate (#0B0F19 or #0F172A) for a crisp developer feel.
o	Accents: Electric Indigo (#6366F1) & Emerald Green (#10B981) for status indicators and active CTAs.
o	Borders/Cards: Translucent dark cards (rgba(255,255,255,0.05)) with subtle 1px border highlights (#1E293B).
•	Typography:
o	Headings & Body: Plus Jakarta Sans or Inter (ultra-readable sans-serif).
o	Technical Badges & Code: JetBrains Mono or Fira Code (monospace).
•	Micro-Interactions: Subtle card hover elevation, glowing gradient borders on active elements, smooth-scroll navigation, and interactive tab switches.
